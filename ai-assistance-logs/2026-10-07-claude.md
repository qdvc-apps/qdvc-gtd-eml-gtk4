**The proposed design** (full detail is in `docs/DESIGN.md`)

- **Window:** a Geary-style three-pane window built from nested `Adw.NavigationSplitView`s. Each pane has its own header bar. Dashboard, Performance and Calendar use the full width, and the sidebar never moves.
- **Adaptive:** narrow windows collapse to a navigation stack; see `narrow.png`.
- **Sidebar:** sections are Overview, Workflow, Filters (instead of "Smart Mailboxes"), Accounts and Results. Dropping messages on a folder moves them.

- **Annotations:** each field is edited in place and saved with its own apply button, which is one `gtd metadata set` per field. This replaces the Mac's Edit/Save form.
- **Feedback:**
  - `Adw.Banner` for "N emails waiting in Input [Ingest]".
  - Toasts for completed actions.
  - Alert dialogs that use the CLI's refusal wording.

- **Additions beyond the Mac edition:**
  - Live reload through file monitors, so changes made by the CLI appear automatically.
  - A parse cache kept in `~/.cache`, not in the workspace.
